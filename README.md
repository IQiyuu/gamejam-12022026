# Virus 🦠

Jeu vidéo réalisé dans le cadre d'une **Game Jam** autour du thème **« Virus »**.

Le projet a été développé avec **Unity** dans un temps limité, avec pour objectif de concevoir une expérience jouable à partir du thème imposé.

## 🎮 Présentation

Le thème de cette Game Jam était :

> **Virus**

Le projet a été développé rapidement dans un contexte de Game Jam, permettant de travailler sur la conception d'un jeu, son gameplay et son développement avec Unity.

## 🚀 Lancer le projet

### Prérequis

* Unity
* Unity Hub
* Git

### Installation

Cloner le dépôt :

```bash
git clone https://github.com/IQiyuu/gamejam-12022026.git
cd gamejam-12022026
```

Ouvrir ensuite le projet avec **Unity Hub**.

Une fois le projet ouvert, lancer la scène principale depuis l'éditeur Unity.
